# License recommendation

**Recommended: MIT.** It's the most common license for portfolio projects: anyone can read and reuse the code with attribution, and it signals openness to recruiters and collaborators.

Alternatives:
- **All rights reserved** (no LICENSE file): people can view the code on GitHub but not reuse it. Choose this if you might turn CoffeeChat AI into a product.
- **AGPL-3.0**: others can reuse it, but anyone who runs a modified version as a service must publish their changes.

To apply MIT, add a `LICENSE` file with the standard MIT text, your name, and the year. GitHub's "Add file → Create new file → LICENSE" offers a template.
